CloudFlow DevOps

Proyecto de Ingeniería DevOps

Descripción del proyecto

CloudFlow DevOps implementa un flujo de trabajo utilizando Git, GitHub, GitHub Actions y AWS EC2.

Objetivo

Aplicar control de versiones, estrategias de ramificación, automatización y despliegue en un entorno Cloud.

Tecnologías utilizadas

  • Git para control de versiones.
  • GitHub para alojamiento y colaboración.
  • GitHub Actions para automatización CI/CD.
  • AWS EC2 como entorno Cloud.
  • Apache HTTP Server para publicar el sitio web.
