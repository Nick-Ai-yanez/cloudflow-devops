# CloudFlow DevOps

Proyecto desarrollado para la asignatura Ingeniería DevOps.

## Descripción

CloudFlow DevOps es un proyecto orientado a implementar un flujo de trabajo
DevOps utilizando control de versiones, estrategias de ramificación,
automatización y despliegue en un entorno Cloud.

## Tecnologías utilizadas

- Git
- GitHub
- GitHub Actions
- AWS EC2
- Amazon Linux 2023
- Apache HTTP Server
- HTML
- CSS
- JavaScript
